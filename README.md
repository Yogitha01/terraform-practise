# 🌩️ Infrastructure Automation with Terraform (IaC)

This project demonstrates how to automate cloud infrastructure using **Terraform** — an Infrastructure as Code (IaC) tool developed by **HashiCorp**.  
All configurations are written in `.tf` files and can be reused or modified easily for different environments.

---

## 🧠 Project Overview

In this project, I used **Terraform** to:
- Create and manage infrastructure automatically  
- Demonstrate IaC principles like consistency, automation, and version control  
- Deploy resources through **Terraform commands** rather than manual AWS console steps  

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|----------|
| **Terraform** | Infrastructure as Code tool |
| **AWS (Free Tier)** | Cloud provider |
| **GitHub Codespaces** | Development environment |
| **Git & GitHub** | Version control and project hosting |
